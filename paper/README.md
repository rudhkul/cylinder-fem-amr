# Provenance of the tables and figures

Paper: *Remeshing-induced force oscillations and computational cost in a GPU finite-element
projection solver* (A. Kulkarni).

| File | What |
|---|---|
| `manuscript.tex`, `refs.bib`, `manuscript.pdf` | the manuscript (elsarticle) and its build |
| `highlights.txt` | highlights for submission |
| `tables/*.tex` | generated by `scripts/paper_tables.py` (do not edit by hand) |
| `figures/*.pdf` | generated by `scripts/paper_figures.py` and `scripts/plot_efficiency.py` |

Regenerate (no solver runs): `scripts/make_paper.sh` (tables, figures, then the PDF with latexmk). Binaries named below are builds of
`src/history/v17_2026-11-09_paper` (`cfa_v17_paper`) and of intermediate states between v17 and
the current `src/` (`cfa_v18a..c_review`, each adding the options listed below; `cfa_v18d_review` = `src/`).

Where every number comes from (all with the binary `build/cfa_v17_paper` = `build/cylinder_fem_amr`
of 2026-11-08, v17 defaults, except U3–U5 of DFG 2D-2, which are the v14 runs; v14 and v17 differ
only in AMR code paths, so uniform meshes are unaffected):

| Result | Runs |
|---|---|
| DFG 2D-2, U3–U5 | `runs/v14/timing/U*_r1` |
| DFG 2D-2, A1–A3 | `runs/v17/timing/A*_r1` |
| DFG 2D-2, Δt study (A2) | `runs/paper/d2_A2_dt2`, `runs/v17/timing/A2_r1`, `runs/paper/d2_A2_dt05` |
| Manufactured solution | `runs/paper/mms_L*` |
| Ablations (A1) | `runs/paper/abl_*` against `runs/v17/timing/A1_r1` |
| DFG 2D-3 | `runs/v17/d3/A2`, `A3`; `runs/paper/d3_*` |
| Mesh figures | `runs/paper/snap_d2_A2`, `snap_d3_A2` |
| Re-projection factorial (A1) | `runs/review/abl_projection_{none,both,scheme_current}`, `runs/paper/abl_projection_current`, `runs/v17/timing/A1_r1` |
| 2D-2 Δt study on U4 | `runs/review/d2_U4_dt2`, `runs/v14/timing/U4_r1`, `runs/review/d2_U4_dt05` |

| Rotational-term variants on the MMS (U3, three Δt) | `runs/review/mms_L3_dt*` |

The runs in `runs/paper` come from `scripts/paper_queue.sh build/cfa_v17_paper runs/paper`
(idle-GPU gate before each run; foreign GPU processes would be logged in `runs/paper/CONTAMINATED.log`).

Runs after the external review of the first draft (2026-11-09): `scripts/review_queue.sh`,
`review_queue2.sh`, `review_queue3.sh`. The binaries add options to v17 one after the other:
`cfa_v18a_review` (`--outlet dirichlet`, `--remesh-projection scheme-current`), `cfa_v18b_review`
(outlet parabola scaled to the discrete inflow flux), `cfa_v18c_review` (`--reproject-test`,
`--reproject-shift`), `cfa_v18d_review` (transferred outlet velocities flux-balanced after a remesh)
= current `src/`. Each reproduces v17 at default options to the run-to-run round-off of the atomic
assembly (forces equal to 1e-11 over 400 steps of U3 and A1). Superseded outlet runs of v18a/v18b
(flux mismatch at the outlet on adaptive meshes) are kept in `runs/review/superseded_*`.
Source of v17: `src/history/v17_2026-11-09_paper`.
